## 📖 项目简介

本仓库用于收录与整理网络上公开的 IPTV 直播源播放列表，方便学习播放列表（M3U/M3U8）的格式规范、测试播放器兼容性，以及研究流媒体地址的组织方式。

所有列表均为**纯文本格式**，不含任何二进制媒体文件。项目本身不搭建服务器、不提供在线播放服务。

## ✨ 特性

| 特性 | 说明 |
| :--- | :--- |
| 🗂️ **分类整理** | 按央视、卫视、地方、港澳台、国际等维度分组归档 |
| 📝 **纯文本格式** | 标准 M3U / TXT 播放列表，兼容主流播放器 |
| 🔄 **格式规范** | 统一的 `#EXTM3U` / `#EXTINF` 结构，便于程序解析 |
| 🧪 **便于测试** | 适合作为播放器、解析器的测试样本 |
| 🪶 **轻量无依赖** | 无脚本、无二进制、无后台服务 |

> 💡 播放列表地址的可用性会随时间变化，本项目不对失效地址做持续维护承诺。
